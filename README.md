# Front & Back Burner Plugin

A simple visual to-do list and idea parker for your Agent Zero sidebar. 

Keep active tasks on the **Front Burner** 🔥 and parked ideas for later on the **Back Burner** ⛄. 

## Features
- Visual sidebar button integration.
- Add, remove, and shift items between burners.
- Data persists locally in a JSON file.

## Installation
1. Install via the Agent Zero Plugin Hub or manually place this folder in `/a0/usr/plugins/`.
2. Restart Agent Zero.
3. Click the new "Front & Back Burner" button in your sidebar!
